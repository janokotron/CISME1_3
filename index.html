03 / Entradas y salidas

Mapa rápido de pines

Pines digitales 0–13

0 RX / 1 TXComunicación serie; pueden interferir con la carga del programa.
2 y 3Entradas/salidas digitales e interrupciones externas.
3, 5, 6, 9, 10, 11Salidas PWM compatibles.
13LED integrado L en el UNO R3.

Entradas analógicas A0–A5

A0–A5Lecturas con analogRead(), típicamente 0–1023.
A4 / SDALínea de datos I²C.
A5 / SCLLínea de reloj I²C.
AREFReferencia analógica externa cuando corresponda.

Alimentación

  • 5V: salida de alimentación de 5 voltios.
  • 3.3V: salida de 3.3 voltios, con corriente limitada.
  • GND: tierra común.
  • VIN: entrada de alimentación externa compatible.
  • RESET: reinicia el microcontrolador.
  • IOREF: referencia del nivel lógico para shields compatibles.

Comunicación

  • UART: RX/TX para datos serie.
  • I²C: SDA/SCL para sensores y pantallas.
  • SPI: bus de comunicación expuesto en pines y conector ICSP.
  • PWM: modulación digital; no es voltaje analógico continuo.

No conectes motores directamente a un pin. Usa un controlador de motor y una fuente adecuada.

04 / Primera práctica

Programa tu primer LED

Materiales y pasos

  • Arduino UNO R3 y cable USB de datos.
  • Instala Arduino IDE.
  • Selecciona Arduino UNO y el puerto correcto.
  • Pega el código, verifica y súbelo a la placa.
  • El LED integrado debería parpadear cada segundo.

Este ejemplo utiliza el LED integrado; no requiere componentes externos.

blink.ino · Arduino C/C++ 
void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(1000);

  digitalWrite(LED_BUILTIN, LOW);
  delay(1000);
}
