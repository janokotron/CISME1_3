03 / Conexiones

Entiende los pines

Los pines permiten recibir señales de sensores y controlar dispositivos externos.

Pines digitales · 0 a 13

Se configuran como entradas o salidas y trabajan con estados HIGH y LOW.

0 (RX) y 1 (TX)Comunicación serie. Pueden interferir con la carga del programa.
2 y 3Pines digitales que también admiten interrupciones externas.
3, 5, 6, 9, 10, 11 (~)Salidas PWM para regular, por ejemplo, el brillo de un LED.
13Conectado al LED integrado marcado L.

Entradas analógicas · A0 a A5

El convertidor analógico-digital de 10 bits transforma las mediciones en números.

A0–A5Se leen con analogRead(); normalmente devuelve 0–1023.
A4 / SDALínea de datos para el bus de comunicación I²C.
A5 / SCLLínea de reloj para el bus I²C.
AREFReferencia analógica externa; úsala solo con un circuito adecuado.

Alimentación y tierra

5VAlimentación para módulos compatibles.
3.3VSalida de 3.3 V con corriente limitada.
GNDTierra o referencia común del circuito.
VINEntrada para alimentación externa compatible.
IOREFIndica el nivel lógico de la placa a shields compatibles.
RESETReinicia el microcontrolador al activarse.

Comunicación y señales

  • UART: serie mediante RX y TX.
  • I²C: SDA y SCL; común en sensores y pantallas.
  • SPI: comunicación mediante pines SPI y conector ICSP.
  • PWM: señal digital modulada; no es una salida analógica real.
No conectes motores directamente a los pines. Utiliza un controlador de motor y una fuente adecuada.
04 / Primera práctica

Haz parpadear un LED

Materiales

  • Arduino UNO R3.
  • Cable USB que permita transferir datos.
  • Arduino IDE instalado.
  • Opcional: LED externo, resistencia de 220–330 Ω y cables.

Pasos

  1. Conecta la placa a la computadora por USB.
  2. Abre Arduino IDE y selecciona Arduino UNO y el puerto correcto.
  3. Pega el programa de ejemplo.
  4. Pulsa Verificar y después Subir.
  5. El LED integrado debería parpadear una vez por segundo.

Este ejemplo utiliza el LED integrado, por lo que no necesitas un LED externo.

blink.ino · Arduino C/C++ 
void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(1000);

  digitalWrite(LED_BUILTIN, LOW);
  delay(1000);
}
